# Mesa360 — Sistema de Gestión para Restaurantes

Mesa360 es un sistema web de gestión para restaurantes desarrollado como proyecto académico. Permite centralizar las principales operaciones del restaurante desde una interfaz accesible mediante el navegador.

## Tecnologías utilizadas

- **Backend:** PHP
- **Frontend:** HTML, CSS y JavaScript
- **Base de datos:** MySQL
- **Servidor web:** Apache HTTP Server
- **Sistema operativo del servidor:** Ubuntu Server

## Módulos del sistema

- Dashboard
- Gestión de menú y categorías
- Gestión de clientes y empleados
- Administración de mesas y reservas
- Registro y seguimiento de pedidos
- Control de inventario y movimientos de stock
- Gestión de pagos y métodos de pago
- Reportes
- Inicio de sesión y gestión de acceso por roles

## Base de datos

El archivo `database/schema.sql` contiene la estructura de la base de datos de Mesa360, incluidas sus tablas y relaciones.

## Instalación y configuración

El sistema está diseñado para ejecutarse en un servidor Ubuntu con Apache, PHP y MySQL.

La configuración de la conexión a la base de datos debe realizarse en el entorno de instalación. Las credenciales de acceso deben mantenerse privadas y no deben publicarse en el repositorio.

Consulta los archivos del proyecto para obtener información adicional sobre la configuración y las herramientas de administración.

## Proyecto académico

Mesa360 fue desarrollado como parte de la asignatura **Desarrollo de Proyectos con Software Libre**, aplicando tecnologías de código abierto para la construcción de un sistema web de gestión de restaurantes.
